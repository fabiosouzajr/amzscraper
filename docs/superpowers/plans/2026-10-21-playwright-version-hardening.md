# Playwright Version Hardening Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Fix scraping on Ubuntu 26.04 by upgrading Playwright. Make a missing or mismatched browser fail loudly at startup with the exact fix command, instead of failing on the first scrape with Playwright's misleading `npx playwright install` banner.

**Architecture:** Pin `playwright` to `1.64.1`. Make `postinstall` install Firefox only, and move Chromium (used only by the `backend/test` debug tools) to an opt-in script. A new pure function, `checkFirefoxInstalled()`, checks that the browser this Playwright version expects is on disk. `ScraperService.initialize()` calls it before every launch and throws its message. `server.ts` calls it once at boot and logs a warning without exiting.

**Tech Stack:** Node 22, TypeScript (CommonJS), Playwright 1.64.1, `node:test` + `ts-node/register/transpile-only` (both already installed; no new dependencies).

**Spec:** There is no separate spec. Requirements are items 1–4 of the 2026-10-21 diagnosis, summarised under Background. The root cause is recorded in `.wolf/buglog.json` (`bug-playwright-ubuntu2604`).

## Background (read first)

- The browser revision is tied to the `playwright` npm version. 1.60.0 expects `~/.cache/ms-playwright/firefox-1522`; 1.64.1 expects `firefox-1555`.
- Playwright 1.60.0 has no `ubuntu26.04` build. `postinstall` failed with `ERROR: Playwright does not support firefox on ubuntu26.04-x64`, so `firefox-1522` was never installed.
- A bare `npx playwright install`, run outside `backend/`, used an npx-cached 1.64.1 and installed `firefox-1555`. That revision is already on this machine and **verified to launch** (Firefox 157), so the upgrade needs no download.
- The only Chromium users are the debug analyzers `backend/test/selector-analyzer.ts` and `backend/test/price-selector-analyzer.ts`.

## Global Constraints

- `playwright` version in `backend/package.json`: exactly `"1.64.1"` (no `^`).
- Every documented install command must be exactly: `cd backend && npx --no-install playwright install firefox` (when already inside `backend/`: `npx --no-install playwright install firefox`). Never document a bare `npx playwright install`.
- The browser check must never call `process.exit` and must never be memoized. Installing the browser while the server runs must fix the next scrape without a restart.
- Work on branch `fix/playwright-version-hardening` (repo is on `master`). The working tree has unrelated changes (`.wolf/*`, `frontend/package-lock.json`, `logs/*.pid`, root `package.json`): stage only the files each task lists.

- OpenWolf: after creating files, add them to `.wolf/anatomy.md`; append one line per task to `.wolf/memory.md`.

## Review Focus

1. **Today's exact failure:** a browser is installed, but for another revision. The message must name the expected path and the Playwright version → Task 2, test `reports path, version and install command when executable is missing`.
2. **Unsupported OS:** `firefox.executablePath()` itself throws. The check must return a message, not crash the server → Task 2, test `does not throw when executablePath() throws`.
3. **Browser installed while the server runs:** the next scrape must succeed without a restart → Task 2, test `checks the filesystem on every call`.
4. **Browser missing at boot:** the server must still start and serve the UI and `/health` → Task 3, Step 4.
5. **Stale running process:** `ts-node-dev` watches `src/` only, so a backend started before Task 1 keeps Playwright 1.60 loaded → Task 1, Step 6 restarts the backend.

### Task 2: `checkFirefoxInstalled()` with tests

**Files:**
- Create: `backend/src/services/browser-check.ts`
- Create: `backend/test/browser-check.test.ts`
- Modify: `backend/package.json` (`scripts.test`)
- Modify: `.wolf/anatomy.md` (two new entries)

**Interfaces:**
- Produces (exported from `backend/src/services/browser-check.ts`):

```ts
export const BROWSER_INSTALL_COMMAND = 'cd backend && npx --no-install playwright install firefox';

export type BrowserCheckResult =
  | { ok: true; executablePath: string }
  | { ok: false; message: string };

export interface BrowserCheckDeps {
  executablePath?: () => string;      // default: () => firefox.executablePath() from 'playwright'
  exists?: (path: string) => boolean; // default: fs.existsSync
  playwrightVersion?: string;         // default: version from 'playwright/package.json'
}

export function checkFirefoxInstalled(deps?: BrowserCheckDeps): BrowserCheckResult;
```

- [ ] **Step 1: Add the test script to `backend/package.json`**

```json
"test": "node -r ts-node/register/transpile-only --test test/*.test.ts"
```

The `*.test.ts` glob deliberately skips the existing debug utilities in `test/`.

- [ ] **Step 2: Write the failing tests in `backend/test/browser-check.test.ts`**

Use `node:test` and `node:assert/strict`. Inject every dependency; tests must never touch the real Playwright or the filesystem. Use `P = '/x/firefox-1555/firefox/firefox'` and `V = '1.64.1'`.

```ts
test('returns ok when the executable exists', () => {
  assert.deepEqual(
    checkFirefoxInstalled({ executablePath: () => P, exists: () => true, playwrightVersion: V }),
    { ok: true, executablePath: P });
});

test('reports path, version and install command when executable is missing', () => {
  const r = checkFirefoxInstalled({ executablePath: () => P, exists: () => false, playwrightVersion: V });
  assert.equal(r.ok, false);
  if (r.ok) return;
  assert.ok(r.message.includes(P));
  assert.ok(r.message.includes(V));
  assert.ok(r.message.includes(BROWSER_INSTALL_COMMAND));
});

test('does not throw when executablePath() throws (unsupported platform)', () => {
  const r = checkFirefoxInstalled({
    executablePath: () => { throw new Error('Unsupported platform'); },
    exists: () => true, playwrightVersion: V });
  assert.equal(r.ok, false);
  if (r.ok) return;
  assert.ok(r.message.includes('Unsupported platform'));
  assert.ok(r.message.includes('upgrade "playwright"'));
  assert.ok(r.message.includes(BROWSER_INSTALL_COMMAND));
});

test('checks the filesystem on every call (no caching)', () => {
  let installed = false;
  const deps = { executablePath: () => P, exists: () => installed, playwrightVersion: V };
  assert.equal(checkFirefoxInstalled(deps).ok, false);
  installed = true;
  assert.equal(checkFirefoxInstalled(deps).ok, true);
});
```

- [ ] **Step 4: Implement `checkFirefoxInstalled` in `backend/src/services/browser-check.ts`**
